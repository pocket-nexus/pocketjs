# The shells

Pictures of five devices from the front, for the Pocket3D player
(`../pocket3d-stage.js`). `bun tools/handheld-shells.ts pocket3d` renders them in
Blender (`tools/handheld-models/shells.py`) and writes `profiles.js`.
No picture carries a wordmark or a logo: the objects that are one are left
out of the render.

| Files | Made from | Licence |
| --- | --- | --- |
| `vita.webp`, `vita-parts.webp` | PocketJS's own model of the PCH-2000 (`engine/pocket3d/examples/handheld/assets/ps-vita-2000`) | [Pocket3D License](../../../../../pocket3d/LICENSE) |
| `3ds.webp`, `3ds-parts.webp` | PocketJS's own model of the KTR-001 (`engine/pocket3d/examples/handheld/assets/new-nintendo-3ds`), its lid flat | Pocket3D License |
| `ipod.webp` | Drawn in `shells.py`; no file of anyone else's is read | Pocket3D License |
| `android.webp` | An Android phone of 2014 that is no maker's, drawn in `shells.py`; no file of anyone else's is read | Pocket3D License |
| `psp.webp`, `psp-parts.webp` | **PlayStation Portable (PSP) - EG02** by **Dibad**, <https://sketchfab.com/3d-models/playstation-portable-psp-eg02-b76c7f9158204a39929a9c97d0b813d0> | [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) |

Changes to Dibad's model for these two pictures: the PSP wordmark, the
PlayStation logo and the Memory Stick mark are left out; the keys, the nub
and the shoulder keys are rendered apart from the case; the materials have
finishes the file does not carry (a polished face, satin keys, a bright
band); dark floors stand in the sockets. The two pictures are offered under
CC BY 4.0 as the model is.
