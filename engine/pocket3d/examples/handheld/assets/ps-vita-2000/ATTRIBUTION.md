# PlayStation Vita 2000 (PCH-2000)

Authored in Blender for PocketJS from the photographic references listed in
`tools/handheld-models/references.json`. Geometry and materials use the repository
license. No downloaded device mesh or photographic texture is included.

The editable source is `ps-vita-2000.blend`; rebuild it with
`Blender --background --python tools/handheld-models/build.py -- vita`.
Coordinates are millimetres: X right, Y toward the top, Z out of the screen.
The GLB uses the standard Blender to glTF axis conversion; the profile restores
these axes for the browser and identifies each dynamic display material.

Sony, PlayStation, PS Vita and Nintendo marks identify the represented hardware.
The Vita wordmarks use the Wikimedia Commons vector sources credited in the
reference manifest (PD-textlogo; trademark rights remain with their owners).
Blender's Bfont outlines use DejaVu/Bitstream Vera; the full font license follows.
