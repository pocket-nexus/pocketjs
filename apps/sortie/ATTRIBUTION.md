# Pocket Sortie — attribution

Everything in this directory is either generated by the two scripts here or
written for PocketJS. Nothing was sampled, traced or copied from another work.

## Title-card outlines

`count-*.png` and `title-*.png` are rasterized glyph outlines from **Zen Old
Mincho Black**, published under the **SIL Open Font License 1.1**.

| Copyright | Copyright 2021 The Zen Old Mincho Project Authors (<https://github.com/googlefonts/zen-oldmincho>) |
| License | SIL Open Font License 1.1 — <https://raw.githubusercontent.com/google/fonts/main/ofl/zenoldmincho/OFL.txt> |
| Source file | <https://raw.githubusercontent.com/google/fonts/main/ofl/zenoldmincho/ZenOldMincho-Black.ttf> |
| SHA-256 | `84a80d8bca79d7d9478935045b216ed003ad40fdea5fd9116d524eb26e872cdc` |

The font binary is **not committed**. `gen-assets.ts` downloads it into the
git-ignored `.pocket-build/sortie-fonts/`, verifies the SHA-256 above, and
writes out only the glyphs this MV spells:

> 参 弐 壱 零 起 動 Ｄ Ｏ Ｍ 、 不 在 錆 の 核 心 一 糸 過 程 同 期 率 六 十 全 機 発 進 つ づ く 警 告

Using glyph outlines inside a document or a piece of artwork is an ordinary use
of an OFL font and does not make the result a derivative of the font software
(SIL OFL FAQ 1.8). The committed PNGs carry no font data, no font tables and no
font name; they are pictures of type. Regenerate them with:

```sh
bun apps/sortie/gen-assets.ts
```

## Score

`media/sortie.wav` is synthesized from scratch by `gen-score.ts` — oscillators,
envelopes and an arrangement written in this repository. No sample library and
no recording of any other work is involved. Regenerate it with:

```sh
bun apps/sortie/gen-score.ts
```

## Influence

The MV is composed in the register of 1990s Japanese television title design:
heavy mincho on black, hard cuts on the beat, terminal readouts in Latin
monospace. That is a visual idiom, not an asset: no logo, mark, character,
frame, colour script or piece of music from any other production is reproduced
here. Every word on screen is about PocketJS.
