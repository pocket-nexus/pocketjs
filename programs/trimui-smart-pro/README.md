# Pocket Studio on the TrimUI Smart Pro

This program runs the Pocket Studio room as a game maker on the console itself. See [docs/TRIMUI_SMART_PRO.md](../../docs/TRIMUI_SMART_PRO.md).

```sh
bun tools/trimui-smart-pro.ts room --studio <pocket-studio checkout>
bun tools/trimui-smart-pro.ts asr
bun tools/trimui-smart-pro.ts install
bun tools/trimui-smart-pro.ts auth --proxy http://<computer>:7897
bun tools/trimui-smart-pro.ts run
```
