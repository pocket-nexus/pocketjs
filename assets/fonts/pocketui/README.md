# The pixel face

`pixel-20*.bin` (regular) and `pixel-23*.bin` (bold) are PocketJS font atlases
of W95FA (`../W95FA.otf`, SIL Open Font License 1.1, `../LICENSE-W95FA.txt`),
baked by `tools/pocketui-pixel-font.ts` at raster densities 1 to 4. They are
derived from the font and are under the same licence. PocketUI's Classic
theme draws in this face where an application's pak carries it
(`docs/POCKETUI.md`, "The pixel face").
