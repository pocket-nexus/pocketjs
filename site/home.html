TypeScript, real frameworks

Solid, Vue Vapor or Octane.
On a 333 MHz CPU.

Import signals, refs and hooks from solid-js, vue and octane. PocketJS supplies the components and draws them natively: no DOM, no WebView, no browser engine.

import { createSignal, Show } from "solid-js";
import { Text, View } from "@pocketjs/framework/solid/components";

export default function App() {
  const [count, setCount] = createSignal(0);
  return (
    <View class="w-full h-full flex-col items-center gap-4 p-4 bg-slate-50">
      <Text class="text-xl text-slate-950 font-bold">Count: {count()}</Text>
      <View class="px-4 py-2 rounded-xl shadow-md bg-blue-600 focus:bg-blue-500"
        focusable onPress={() => setCount(count() + 1)}>
        <Text class="text-base text-white font-bold">Press Circle</Text>
      </View>
      <Show when={count() > 3}>
        <Text class="text-sm text-emerald-600">Reactive on real hardware.</Text>
      </Show>
    </View>
  );
}
import { ref } from "vue";
import { Text, View } from "@pocketjs/framework/vue-vapor/components";

export default function App() {
  const count = ref(0);
  return () => (
    <View class="w-full h-full flex-col items-center gap-4 p-4 bg-slate-50">
      <Text class="text-xl text-slate-950 font-bold">Count: {count.value}</Text>
      <View class="px-4 py-2 rounded-xl shadow-md bg-blue-600 focus:bg-blue-500"
        focusable onPress={() => { count.value++; }}>
        <Text class="text-base text-white font-bold">Press Circle</Text>
      </View>
      {count.value > 3 ? (
        <Text class="text-sm text-emerald-600">Reactive on real hardware.</Text>
      ) : null}
    </View>
  );
}
import { useState } from "octane";
import { Text, View } from "@pocketjs/framework/octane/components";

export default function App() {
  const [count, setCount] = useState(0);
  return (
    <View class="w-full h-full flex-col items-center gap-4 p-4 bg-slate-50">
      <Text class="text-xl text-slate-950 font-bold">{`Count: ${count}`}</Text>
      <View class="px-4 py-2 rounded-xl shadow-md bg-blue-600 focus:bg-blue-500"
        focusable onPress={() => setCount(count + 1)}>
        <Text class="text-base text-white font-bold">Press Circle</Text>
      </View>
      {count > 3 ? (
        <Text class="text-sm text-emerald-600">Reactive on real hardware.</Text>
      ) : null}
    </View>
  );
}

Modern UI

And everything a modern
screen expects.

On top of that engine: the layout, type, motion and input people know from their phones.

Layout

Flexbox and utility classes, sized to any screen.

Rows, columns, gaps, rounded corners and shadows, written as classes you already know. The same app fills a tall touch screen and a wide tablet panel.

Text

Sharp type in every script.

Latin, Chinese and Japanese, crisp at small sizes. Lists, transcripts and editors read the way they do on a phone.

Animation

Springs and keyframes that keep their pace.

Motion compiles at build time and runs inside the native engine, with no JavaScript per frame, so it stays smooth while your app is busy.

Motion studies by yui540, ported with permission (yui540).

Input

Touch, buttons, keyboards and focus.

Tap, swipe, scroll, type, or move focus with a d-pad. One app answers whichever input the device has.

PocketUI

Adaptive components. Themes that switch live.

PocketUI gives a Solid app panes, feeds, menus, forms and a full text editor. Each part adapts to the screen and its controls, and a theme restyles the whole app while it runs: your typing, scroll position and focus stay put.

import { mountPocketUI } from "@pocketjs/framework/ui";
